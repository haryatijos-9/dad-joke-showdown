One dad joke, written to be told out loud at the dinner table:

> I told my guitar it was out of tune. It said, "I'm just fretting about it."

`main.py` scores six original jokes against the judge's five criteria
(dad-joke-ness, clean pun, freshness, tightness, reads aloud — weights
5/4/3/2/1) and writes the winner to `/output/entry.txt`. Run it with
`python3 main.py`.
